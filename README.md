# Waaxalma

> Speak for me.

Waaxalma is an open-source AI Voice Agent Framework that enables multilingual communication using AI.

## Current status

🚧 Prototype (v0.1)

## Features

- FastAPI backend
- Streamlit interface
- Voice recording
- Speech-to-Text
- Translation
- Text-to-Speech
- Multi-Agent architecture
- Session management
